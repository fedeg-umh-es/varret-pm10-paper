Data Availability Statement

Raw daily PM10 observations were obtained from the MITECO Spanish national air-quality network portal (https://www.miteco.gob.es/) and are publicly available. Processed per-station series, the 595-cell aggregate diagnostic tables (variance retention, Diebold-Mariano significance, exceedance, Murphy decomposition), and the exact source tables underlying every multi-station figure are version-controlled at https://github.com/fedeg-umh-es/varret-pm10-paper under evidence/paper_a/ (SHA-256 checksums and provenance recorded in evidence/paper_a/manifests/provenance_manifest.csv). The row-level prediction set (895,737 rows spanning all 17 stations, 5 model families, and 7 horizons) is documented by SHA-256 hash and structure in evidence/paper_a/row_level/predictions_all_stations_manifest.md; it is archived locally with that checksum and prepared for release as a GitHub release asset of the same repository, and is available from the corresponding author on request pending that release. It is not embedded in the git history itself due to its size. The Supplementary Material contains the PRISMA reporting-audit outputs and the full monitoring-station table referenced in the main text.
