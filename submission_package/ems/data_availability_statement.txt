Data Availability Statement

Raw daily PM10 observations were obtained from the MITECO Spanish national air-quality network portal (https://www.miteco.gob.es/) and are publicly available. Processed per-station series, the 595-cell aggregate diagnostic tables (variance retention, Diebold-Mariano significance, exceedance, Murphy decomposition), and the exact source tables underlying every multi-station figure are version-controlled at https://github.com/fedeg-umh-es/varret-pm10-paper under evidence/paper_a/ (SHA-256 checksums and provenance recorded in evidence/paper_a/manifests/provenance_manifest.csv). The row-level prediction set (895,737 rows spanning all 17 stations, 5 model families, and 7 horizons) is available as a versioned GitHub release asset of the same repository (tag paper-a-row-level-evidence-v1), with its SHA-256 checksum reported in evidence/paper_a/row_level/predictions_all_stations_manifest.md and in the release notes. It is not embedded in the git history itself due to its size. This row-level file directly supports independent recomputation of variance retention (alpha), collapse, and near-ideal classification for all 595 station-model-horizon cells, and of persistence-relative RMSE skill for the four non-SARIMA model families; SARIMA's cell-level skill was computed against a wider persistence baseline (skill_sarima_{station}.csv) not included in this row-level release, as documented in the manifest. The Supplementary Material contains the PRISMA reporting-audit outputs and the full monitoring-station table referenced in the main text.
