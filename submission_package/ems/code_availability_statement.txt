Code Availability Statement

The Python scripts for rolling-origin evaluation, model fitting, metric computation, and manuscript figure/table rendering are archived and version-controlled at https://github.com/fedeg-umh-es/varret-pm10-paper. The row-level prediction file (predictions_all_stations.csv) directly supports independent recomputation of variance retention (alpha), collapse classification, and near-ideal classification for all 595 station-model-horizon cells: recomputing these from the row-level rows matched the published aggregate tables to floating-point precision (maximum absolute difference on alpha: 1.68e-13); see evidence/paper_a/README.md and outputs/p3_12r_artifact_consolidation/recomputation_comparison.csv for the verification record.

RMSE skill (persistence-relative) is independently reproducible from the row-level file for 476 of 595 cells (all four non-SARIMA model families). The 119 SARIMA cells are the exception: SARIMA's own predictions span 2018-2024, but the row-level file's persistence rows span 2020-2024 only, so the exact pairs needed to recompute SARIMA's skill are not present in this export. SARIMA's published skill values are correct and were computed with an exact same-pair (station, origin, forecast date, horizon) comparison against persistence, recorded in skill_sarima_{station}.csv (generated by scripts/02_generate_sarima_predictions.py) before table consolidation — but that specific pairing is not re-derivable from predictions_all_stations.csv alone. This affects only the row-level reproducibility of SARIMA's cell-level skill; it does not affect alpha, collapse, or near-ideal classification for SARIMA, nor any metric for the other four model families.
