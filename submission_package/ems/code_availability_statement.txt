Code Availability Statement

The Python scripts for rolling-origin evaluation, model fitting, metric computation, and manuscript figure/table rendering are archived and version-controlled at https://github.com/fedeg-umh-es/varret-pm10-paper. All diagnostic metrics (variance retention, skill, collapse and near-ideal classification) were independently recomputed from the row-level predictions with a Python 3.12 environment (numpy, pandas, matplotlib, scipy, pyarrow) and matched the published aggregate tables to floating-point precision (maximum absolute difference on alpha: 1.68e-13 across 595 station-model-horizon cells); see evidence/paper_a/README.md and outputs/p3_12r_artifact_consolidation/recomputation_comparison.csv for the verification record.
