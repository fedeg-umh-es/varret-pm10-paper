\section{Metrics}
\label{sec:metrics}

\subsection{Persistence-relative skill}
For matched forecast--observation pairs, persistence-relative RMSE skill is
\begin{equation}
\mathrm{Skill}=1-\frac{\mathrm{RMSE}_{model}}{\mathrm{RMSE}_{persistence}}.
\end{equation}
Positive values indicate lower RMSE than persistence; they do not by themselves establish dynamic fidelity.

\subsection{Variance retention}
The canonical diagnostic is the predicted-to-observed variance ratio
\begin{equation}
\alpha=\frac{\operatorname{Var}(\hat y)}{\operatorname{Var}(y)},
\end{equation}
with population variances ($\mathrm{ddof}=0$) over the matched cell pairs. Thus $\alpha=0.50$ means that one half of the observed variance is retained; it is not a standard-deviation ratio. The canonical implementation also computes descriptive percentile-bootstrap intervals with $B=1000$ resamples and seed 42.

\subsection{Significance and event sensitivity}
The Diebold--Mariano loss differential uses squared-error loss against persistence. The implementation applies the Harvey--Leybourne--Newbold small-sample correction with horizon-dependent autocovariance truncation and adjusts valid p-values using Benjamini--Hochberg within each dataset. P75 recall is the proportion of observed P75 exceedances correctly forecast as exceedances, using thresholds estimated from the corresponding training window. These diagnostics are used jointly in Rule B; none is presented as a universal replacement for error metrics.
