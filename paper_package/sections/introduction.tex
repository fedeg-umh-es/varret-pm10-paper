\section{Introduction}
\label{sec:introduction}

Daily PM$_{10}$ forecasts support air-quality monitoring and short-term public-health decisions. Forecast verification therefore has to distinguish genuine predictive improvement from performance that is attractive only under an aggregate error score.

Conventional evaluation usually begins with a reference forecast and a scale-dependent error measure. Persistence-relative skill is useful because it asks whether a candidate improves on a simple, operationally interpretable comparator, while Diebold--Mariano testing provides a formal comparison of forecast losses \cite{hyndman2006,diebold1995}. These tools are necessary for model comparison, but they do not describe the dynamic spread of the forecast trajectory.

A point forecast can reduce RMSE by attenuating fluctuations. Such attenuation may be acceptable for some decisions, but it can also reduce the amplitude of pollution episodes and make a forecast appear preferable under error criteria while failing a complementary fidelity check. Forecast verification literature treats accuracy, association, and other dimensions as related but non-equivalent properties \cite{gneiting2011,jolliffe2012}. The practical question is consequently not whether error metrics should be discarded, but whether adding a transparent dynamic-fidelity audit changes which model cells remain eligible.

This study asks: \emph{Does incorporating dynamic-fidelity criteria alongside conventional error-based statistical evaluation materially alter model-selection decisions in multi-step PM$_{10}$ forecasting?} We answer with a post-evaluation decision audit of a fixed empirical benchmark. The contributions are limited to three points:
\begin{enumerate}
    \item an empirical audit of error--fidelity discordance;
    \item a description of its variation by model family and horizon; and
    \item a quantification of how an explicit fidelity requirement changes eligibility.
\end{enumerate}
