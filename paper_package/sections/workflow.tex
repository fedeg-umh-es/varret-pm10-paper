\section{Evidence Governance and Reproducibility}
\label{sec:workflow}

The empirical analysis is governed by a frozen 595-row diagnostic table whose SHA-256 is recorded in the provenance manifest. The table contains the complete five-model, 17-station, seven-horizon grid and is the sole source for the numerical results, tables, and primary figures in this manuscript.

Reproducibility is separated into two layers. The scientific layer defines the forecast task, validation controls, metrics, eligibility rules, and limitations in the sections above. The computational layer preserves source tables, provenance records, deterministic table and figure generators, and a claim-level traceability matrix in the repository package. The final submission archive contains only LaTeX inputs and figures needed for compilation; internal audit material remains outside that archive.

The sensitivity analysis is a deterministic transformation of the frozen rows. It changes neither forecasts nor thresholds used for the primary result. Its purpose is to show how the eligibility consequence behaves in a prespecified neighbourhood of the operational thresholds.
