# P3-08 — EMS Adaptation Outputs Directory

This directory contains all audit files and verification manifests for task **P3-08: Adaptar Paper A a Environmental Modelling & Software**.

## File Inventory

- `README.md`: Overview of P3-08 output files.
- `current_journal_requirements.csv`: Official requirements audit for *Environmental Modelling & Software*.
- `template_manifest.sha256`: SHA-256 hashes of the downloaded official `elsarticle` template files.
- `before_manifest.csv`: Initial snapshot hashes of pre-adaptation manuscript files.
- `title_options.md`: Evaluated title options for submission to EM&S.
- `highlights.txt`: Official highlights text file (5 bullet points, max 85 chars each).
- `highlights_audit.csv`: Character count and compliance audit for highlights.
- `abstract_change_audit.csv`: Audit of abstract formatting changes.
- `section_mapping.csv`: Section-by-section mapping between canonical and adapted manuscript.
- `symbol_audit.csv`: Verification of mathematical notation and symbol definitions.
- `reference_format_audit.csv`: Audit of bibliography references against `elsarticle-num-names.bst`.
- `figure_submission_audit.csv`: Compliance and format audit for all 11 figure files.
- `table_submission_audit.csv`: Compliance audit for manuscript tables.
- `supplement_mapping.csv`: Mapping of supplementary material sections and files.
- `declaration_audit.csv`: Verification of mandatory Elsevier declarations.
- `data_code_statement_options.md`: Options for data and code availability statements.
- `length_audit.json`: Word count and page limit compliance audit.
- `pdf_visual_audit.md`: Page-by-page visual inspection report of `paper_a_ems.pdf`.
- `scientific_invariance_audit.csv`: 100% verification of scientific invariance against canonical numbers and claims.
- `desk_reject_surface_ems.md`: Desk-reject surface assessment for *Environmental Modelling & Software*.
- `submission_file_audit.csv`: Inventory and audit of all submission package files.
- `adaptation_summary.json`: Machine-readable summary of the adaptation process.
- `final_report.md`: Final executive audit report.
