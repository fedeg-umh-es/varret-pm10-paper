# Data and Code Availability Statements for EM&S Submission

## Option 1 (Recommended - Bounded & Fully Transparent):
**Data Availability Statement:**  
The analysis code, configuration files, and evaluation scripts used in this study are openly available at \url{https://github.com/fedeg-umh-es/varret-pm10-paper}. Raw daily PM$_{10}$ observations were obtained from the MITECO Spanish national air-quality network portal (\url{https://www.miteco.gob.es/}) and are publicly available. The Supplementary Material contains the PRISMA reporting-audit outputs and the full monitoring-station table referenced in the main text.

**Code Availability Statement:**  
The Python and R scripts for rolling-origin evaluation, model fitting, metric computation, and manuscript figure/table rendering are archived and version-controlled at \url{https://github.com/fedeg-umh-es/varret-pm10-paper}. All diagnostic metrics can be reproduced directly from the provided evidence package.
