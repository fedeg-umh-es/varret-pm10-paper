# P3-07 — Journal Routing Outputs

This directory contains the audit artifacts produced during task **P3-07: Confirmar revista destino para Paper A**.

## Inventory of Journal Routing Artifacts

- `README.md`: Overview of the journal routing audit directory.
- `manuscript_editorial_profile.md`: Detailed extraction of Paper A's editorial profile, contribution type, and scope boundaries.
- `reference_journal_audit.csv`: Analysis of journals cited in `references.bib`.
- `journal_longlist.csv`: Initial longlist of candidate journals audited against project constraints.
- `current_facts_audit.csv`: Verified facts regarding publication models, APC fees, indexing, and institutional agreements.
- `recent_article_scan.csv`: Scan of recent articles (2024–2026) across top candidate journals to assess novelty risk.
- `journal_decision_matrix.csv`: Qualitative multi-criteria decision matrix evaluating all candidate journals.
- `exclusion_log.csv`: Explicit log of excluded journals and deselected options with evidence.
- `target_journal_gap_audit.csv`: Gap analysis comparing canonical manuscript against target journal expectations.
- `routing_decision.json`: Machine-readable summary of the routing decision.
- `final_routing_report.md`: Executive summary report of the target journal selection.
