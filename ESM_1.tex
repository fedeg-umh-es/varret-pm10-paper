\noindent\textbf{Definitions and multiplicity.} The paired loss differential is
$d_t=L_{\mathrm{lags}}-L_{\mathrm{lags+meteorology}}$, so positive statistics favour the lags + meteorology information set.
The primary specification uses $q_{\mathrm{overlap}}=0$; the sensitivity uses the fixed Bartlett/Newey--West bandwidth
$q=\lfloor4(n/100)^{2/9}\rfloor$. The global Bonferroni family contains 36 planned comparisons, and
Benjamini--Hochberg adjustment is applied across the four horizons within each station. No cell survives global
Bonferroni correction. Non-significance is not evidence of equivalence.
